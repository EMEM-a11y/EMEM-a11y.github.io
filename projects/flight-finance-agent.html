整套出报链路

难点不是让 AI 出一张报表，而是同时保证稳定与灵活。

固定月报需要严格遵循已验收模板和指标口径，临时业务问题又要求系统能够自主分析。单一 Workflow 不够灵活，单一 Agent 又难以保证稳定交付，因此我设计了双链路方案。

Workflow + 动态 Agent 双链路

固定任务走验收链路，临时问题走自主分析链路，两者共享同一套数据口径和安全保障。

固定月报

Workflow 保证稳定出报

调用已验收模板，按固定顺序执行并完成结果勾稽。

  1. 参数确认
  2. QBI 取数
  3. 模板生成
  4. 结果勾稽
临时问题

动态 Agent 自主规划分析

基于字段字典、指标口径和表关系理解问题并组织分析。

  1. 解析问题
  2. 规划分析
  3. 生成 SQL
  4. 调用 QBI
  5. 输出结论
共同保障 数据权限 异常拦截 人工重试
